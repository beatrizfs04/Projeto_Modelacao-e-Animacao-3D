# Projeto_Modelacao-e-Animacao-3D
## O que foi feito?
O objetivo deste projeto foi aprofundar e avaliar os principais conceitos e ferramentas de modelagem, bem como as técnicas de criação e manipulação de texturas/UVs e materiais em um ambiente 3D.

### Implementações:
- Desenvolvimento de 4 objetos.
- 1 objeto utiliza a técnica de conversão de highpoly para lowpoly.
- Todos os objetos possuem imagens de referência.
- Todos os objetos possuem UVs e texturas.
- Os materiais utilizam múltiplas texturas (Albedo, Roughness, Normal and Metallic).
- O arquivo contém todos os 4 objetos com configurações de materiais/iluminação.

## Quem participou?
Este projeto foi realizado por mim, aluna do Mestrado de Desenvolvimento de Jogos Digitais.

## Que tecnologias foram utilizadas?
- Blender
